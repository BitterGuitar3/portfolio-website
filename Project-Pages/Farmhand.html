About

Farmhand was the second prototype I built during the Unity Learn Junior Programmer Pathway. The focus of this project was learning how to implement basic gameplay mechanics. The player controls a character who feeds animals by shooting food at them before they exit the screen or collide with the player.

While simple in concept, the prototype introduced important gameplay concepts like random object spawning, health-style UI, and object pooling for performance efficiency.

Features and Mechanics

  • Core Gameplay: The player moves left and right using A/D keys and presses Spacebar to shoot food. The objective is to feed as many animals as possible before losing all lives.
  • Dynamic Spawning: Animals spawn randomly from the left, right, or top of the screen, with randomized positions and movement directions.
  • Feeding System: Each animal has a slider-style "hunger bar" UI that fills when hit with food. Larger animals require more food to be fed successfully.
  • Scoring & Lives: Players earn points for each fed animal, based on how much food was required. Lives are lost if animals reach the edge of the screen or collide with the player.

What I Learned

This project helped expand my understanding of Unity in a few important ways:

  • Object Instantiation: Learned how to use Random.Range() and Instantiate() to spawn game objects at randomized intervals and positions.
  • Object Pooling: Built a simple object pooling system for food projectiles to reduce CPU overhead and avoid unnecessary instantiations/destructions — improving performance and game responsiveness.
  • Collision Handling: Gained hands-on experience with OnTriggerEnter() to manage interactions between food and animals. Learned when to use triggers versus colliders to avoid unintended physics reactions.
  • UI Mechanics: Implemented UI elements (sliders) that update in real-time to communicate progress to the player — reinforcing responsive game feedback.

Reflection

Though Farmhand is a small prototype, it introduced me to a wide range of systems that are foundational to gameplay programming: object pooling, collision logic, UI integration, and randomization. It was also the first project where I felt I was designing a real gameplay loop and balancing challenge, pacing, and player feedback.
