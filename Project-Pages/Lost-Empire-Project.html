Name: Lost Empire Project

Project Type: Prototype

Basic Info

  • Engine: Unity
  • Role: Gameplay Programmer (AI Systems / Player Controller)
  • Timeline: 4.5 months
  • Team: 7-9 (primary gameplay systems contributor)

About

A gameplay systems contribution to an indie project, focused on implementing core player control architecture and AI behavior systems using scalable, data-driven patterns.

This work was completed as part of a team collaboration and is presented at a high level due to NDA restrictions.

Core Contributions

  • Player Controller System
    • Implemented FSM-based player controller supporting movement states such as walking, sprinting, crouching, jumping, and dashing
    • Designed state-driven structure to ensure consistent input handling and animation synchronization
    • Integrated combat-ready movement transitions (aiming and shooting states)
  • AI Behavior System
    • Developed NPC decision-making using Behavior Trees with Blackboard architecture
    • Built flexible blackboard system supporting generic key-value configuration for runtime AI variation
    • Enabled configurable AI profiles through structured parameters (behavior type, movement logic, and combat style)
  • Navigation & World Interaction
    • Integrated Unity NavMesh-based navigation with support for area masking and restricted zones
    • Supported early-stage AI spatial awareness systems for detection and engagement behavior
    • Designed foundation for expandable faction/awareness logic system

Technical Focus

  • FSM-based gameplay architecture
  • Behavior Tree AI design patterns
  • Blackboard-driven AI configuration system
  • Unity NavMesh pathfinding systems
  • Scalable gameplay logic design using polymorphism and modular state separation

Notes

Work was developed in a collaborative environment with a focus on maintainable gameplay architecture and extensible AI systems under project constraints.
