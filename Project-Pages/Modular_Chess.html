Name: Modular Chess

Project Type: Playable Prototype

Basic Info

  • Engine: Unity 6.3
  • Role: Gameplay Programmer / Systems Designer
  • Timeline: 14 weeks
  • Team: Solo
Chess Engine Core Repo Itch.io Page

Core Systems

  • Modular Rule System
    • Gameplay modifiers applied at runtime to alter core chess rules
    • Supports stacking and ordering of multiple rule changes per match
  • Pre-Game Configuration System
    • Players select and combine modifiers before match starts
    • Rule set is constructed dynamically based on selection order
  • Core Chess Engine
    • Fully playable local hot-seat implementation
    • Standard movement and win-condition validation system
  • Board State Systems
    • Turn-based state tracking with dynamic rule evaluation
    • Experimental mechanics such as board flipping per turn

Design Focus

  • Interaction between multiple rule-modifying systems
  • Emergent gameplay through layered mechanics
  • Exploring complexity growth in familiar strategy frameworks

Current Status

  • Playable prototype
  • Core systems functional and extensible
  • Ongoing iteration on mod interactions and rule clarity
