Name: Character Selection

Project Type: Prototype

Basic Info

  • Engine: Unity
  • Role: Programmer
  • Timeline: 2 Hours
  • Team: Solo Project

About

This was just a simple challenge presented to me while working on the Junior Programmer pathway on Unity Learn. The goal was to make a prototype of some kind of feature or mechanic in a game. I was interested in creating some kind of selection screen for characters like you would see in a game where you chose your character class in a story or in a multiplayer pvp game. So I made this prototype. I mimiced the kind of camera angle you would see and created the basic shapes to just represent the player models. When the player clicked on the shape, some text would pop up describing the character.

This basic model gave me the foundation of being able to create something more complicated if I ever want to. I imagine the character doing some kind of animation and saying some kind of catchphrase. I picture a sound effect plays when you highlight them and select them for the game. I see an alternate verison of this would selection screen can be like the Dark Souls games where you have the titles in a box on the left of the types of characters and you can see the character you selected on the right side. There are so many places where this prototype can be used that it would be impossible to list them all.

What I learned

So while working on this prototype, I had to learn a bit more about the Unity Engine and its built in features. I needed to understand how the box colliders work as well how to get input from the mouse for it to trigger an event. Once that event is triggered the invisible text box that is on screen gets sent the text that is stored within the script the each character had so that the text changed whenever a new character got selected. Nothing too complicated looking back at it, but it also taught me how to properly look up a bit of documentation on the Unity game engine and understanding the strutcure of the documentation itself.
