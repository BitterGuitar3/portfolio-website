Project Overview / Game Direction

Project Delve is intended to become a fast-paced, reactive 2D roguelite dungeon crawler set in a dark medieval fantasy world. The game is centered around movement, timing, positioning, and aggressive combat, with procedurally generated dungeon runs creating escalating risk and reward. Players will gain temporary buffs and rewards throughout each run, allowing their playstyle to adapt based on the choices and rewards they encounter. Each run will ultimately progress through themed floors and culminate in boss encounters designed to test mastery of the game's core combat systems.

Core Systems

  • Player & Combat Architecture
    • Gameplay systems structured to separate input requests from gameplay logic, allowing for potential future multiplayer support
    • Separation of input, character control, weapon logic, combat, and health responsibilites
    • Sword-based melee combat with hit detection and attack cooldowns
    • Combat roll with directional movement and cooldown
    • Enemy AI with pursuit and timed attacks
    • Damage feedback including audio, hit flashes, and screen shake
  • Procedural Dungeon Generation
    • Modular room-based dungeon generation
    • Multiple room layouts for combat encounters
    • Procedurally generated room connections
    • Start, combat, loot, and boss room types
    • Dungeon layouts generated dynamically at runtime
  • Enemy & Encounter Systems
    • Basic melee enemy with player tracking and attack behavior
    • Encounter-based room progression
    • Enemy health and damage systems
    • Boss encounter using an expanded enemy configuration
    • Player death and retry flow
    • Encounter System
      • Rooms lock when combat begins
      • Players must defeat all enemies before progressing
      • Combat encounters are integrated into procedural room generation
  • Game Flow & UI
    • Procedurally generated run from starting room to boss encounter
    • Loot rooms containing basic health recovery
    • Boss defeat and reward interaction (another basic health potion)
    • Basic health, enemy health, pause, and main menu UI

Design Focus

  • Procedural dungeon generation and room composition
  • Building a modular foundation for roguelite gameplay systems
  • Creating repeatable dungeon-crawler gameplay loops
  • Exploring encounter pacing through room layouts and enemy placement
  • Developing gameplay systems with clear separation of responsibilities
  • Designing systems that can be expanded as the project develops
