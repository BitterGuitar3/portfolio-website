Core Systems

  • First-Person Combat System
    • Weapon equip / reload / swap system
    • ADS implementation with camera + IK blending
    • Basic sprint, crouch, jump movement
  • AI Combat System
    • NPC with mirrored player capabilities
    • Distance-based accuracy system
    • Cover-seeking behavior using environmental awareness
    • Decision-making under low ammo conditions
  • Inventory & Weapon Framework
    • Dual-slot weapon system (player + AI)
    • Dynamic pickup, drop, and swap logic
    • Shared interaction rules between entities
  • Interaction & World Systems
    • Ammo and weapon pickup system
    • Basic HUD for ammo tracking
    • Pause system (game continues running in the background to simulate online multiplayer behavior)

Technical Focus

  • Blueprint-based gameplay architecture
  • AI behavior tree-driven decision system
  • Modular interaction and weapon handling systems
  • Early-stage foundation for scalable shooter framework

Notes / Development Context

Built as a first Unreal Engine project to explore core FPS systems and AI behavior in a constrained environment before scaling toward larger tactical gameplay.

Key focus was on:

  • Rapid prototyping of core mechanics
  • Establishing reusable gameplay systems
  • Understanding Unreal AI and animation workflows
