About

Sky Cleaner is a self-directed Unity Project developed while completing Unity's Junior Programmer pathway. It served as my first full end-to-end game development cycle, where I applied foundational programming and design concepts to build a complete playable arcade-style experience.

The project is inspired by classic arcade shooters such as Galaga, and focuses on building a simple but complete gameplay loop centered around movement, shooting, and scoring.

Core Systems

  • Player Control System
    • 3D flight-style movement using WASD input
    • Limited-ammo shooting system (3-shot constraint)
    • Visual feedback through plane tilt, animation, and movement effects
  • Enemy Spawning System
    • Randomized enemy spawn positions just outside the play area
    • Lightweight procedural spawning logic for replayability
    • Difficulty scaling through spawn rate adjustment
  • Scoring System
    • Points awarded for destroying targets
    • Higher reward for skill-based actions vs collision-based outcomes
    • Runtime score tracking during gameplay sessions
  • Audio & Feedback Systems
    • Basic sound effects for shooting, hits, and destruction
    • Background music selected to reinforce arcade tone

Development Focus

The primary goal of this project was to strengthen my understanding of Unity's core systems and workflow, including component-based architecture, scene orginazation, and gameplay scripting in C#.

It also served as practice in completing a full development cycle-from prototype to playable build-while managing scope and maintaining a consisten gameplay loop.

Key Learnings

  • Object-oriented programming applied to real gameplay systems
  • Unity component-based architecture and scene management
  • Structuring a complete gameplay loop from scratch
  • Basic difficulty scaling and player feedback systems
  • Completing a project independently from start to finish

Notes

This project was developed early in my learning process and primarily reflects foundational implementation work rather than advanced architecture or system design. It represents an important baseline project in my progression toward more complex gameplay programming work.
